# Smart Event Management System

## About the Project

The Smart Event Management System is a Java-based application developed as an Object-Oriented Programming mini-project. It helps organizers manage events, participants, teachers, judges, invitations, attendance, and venue capacity.

## Features

- Event details management
- Separate participant, teacher, and judge records
- Excel import for student and teacher details
- Email invitations
- Attendance tracking and entry validation
- Venue capacity and crowd monitoring
- Pass management

## Technologies Used

- Java 21
- Apache Maven
- Apache POI for Excel processing
- Git and GitHub

## How to Run

1. Install JDK 21 and Apache Maven.
2. Clone the repository.
3. Open the project directory in the terminal.
4. Compile the project:

   ```bash
   mvn clean compile
   ```

5. Run `Main.java` from your Java IDE.

## Object-Oriented Programming Concepts

- Classes and objects
- Encapsulation
- Inheritance
- Interfaces
- Polymorphism, where implemented
- Exception handling
